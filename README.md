# L'IA en marketing, communication et relation client

Cours interactif en quatre séances du module « L'IA dans les fonctions de l'entreprise » (Bachelor 2).

Page publiée : https://pierrickbriand.github.io/ia-claude-projet-slip-francais/

Le diaporama tient dans un seul fichier, `index.html`. Les réponses des étudiants restent dans leur navigateur. L'export PDF est créé sur leur appareil.

## Édition étudiante

Ce dépôt contient uniquement l’édition étudiante : sans corrigés, sans notes de l’enseignant et sans tableau de bord. L’édition enseignant n’est pas publiée ici.
