# L'IA dans les fonctions de l'entreprise

Cours interactif en quatre séances (Bachelor 2). Au démarrage, chaque groupe de 1 à 4 étudiants choisit sa marque fil rouge : Le Slip Français, Veja, Faguo, Loom, Jules & Jenn ou Asphalte.

Page publiée : https://pierrickbriand.github.io/ia-claude-projet-slip-francais/

Le cours tient dans un seul fichier, `index.html`. Les réponses des étudiants restent dans leur navigateur. Les exports PDF et les sauvegardes .json sont créés sur leur appareil.

## Édition étudiante

Ce dépôt contient uniquement l’édition étudiante : sans corrigés, sans notes de l’enseignant et sans tableau de bord. L’édition enseignant n’est pas publiée ici.

Les faits sur les marques viennent de sources publiques consultées en octobre 2026. Les données de ventes sont fictives.
